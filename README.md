# Airport Hub - Application Mobile

Application mobile développée avec React Native et Expo pour la gestion des opérations aéroportuaires.

## 📱 Fonctionnalités

- Navigation fluide entre les écrans avec React Navigation
- Gestion des fichiers et documents avec expo-file-system
- Sélection de documents avec expo-document-picker
- Gestion des dates avec @react-native-community/datetimepicker
- Interface utilisateur moderne avec des dégradés (expo-linear-gradient)
- Compatible iOS et Android

## 🚀 Prérequis

- Node.js (version 14 ou supérieure)
- npm ou yarn
- Expo CLI installé globalement (`npm install -g expo-cli`)
- Un émulateur iOS/Android ou un appareil physique pour le test

## 🛠 Installation

1. Cloner le dépôt :
   ```bash
   git clone [URL_DU_REPO]
   cd mobile-app
   ```

2. Installer les dépendances :
   ```bash
   npm install
   # ou
   yarn install
   ```

3. Démarrer l'application :
   ```bash
   # Pour iOS
   npm run ios
   # ou pour Android
   npm run android
   # ou pour le web
   npm run web
   ```

## 📂 Structure du projet

```
mobile-app/
├── assets/           # Images, polices et autres ressources
```

## 🛠 Technologies utilisées

- **React Native** - Framework de développement mobile
- **Expo** - Outils et services pour React Native
- **TypeScript** - Typage statique pour JavaScript
- **React Navigation** - Gestion de la navigation
- **Expo File System** - Gestion des fichiers
- **React Native Reanimated** - Animations fluides
